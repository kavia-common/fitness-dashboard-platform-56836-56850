# fitness_frontend

React app for the Fitness Dashboard Platform.

## Run locally

```bash
npm install
npm start
```

## Configuration

Set these environment variables (via orchestrator / deployment):

- `REACT_APP_API_BASE` (preferred) or `REACT_APP_BACKEND_URL`
- `REACT_APP_FRONTEND_URL` (optional)
- `REACT_APP_WS_URL` (optional)
- `REACT_APP_PORT` (default 3000)
